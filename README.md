# Facebook Clone

This project is a **Facebook homepage clone** built using **HTML and CSS**. I created this project while learning **Git and GitHub** as part of our Git tutorial. The main goal of this project was to practice version control, understand the Git workflow, and gain hands-on experience with repository management while building a simple web page.

The clone recreates the basic layout and appearance of Facebook's landing page, including the navigation bar, login section, and responsive content structure. Although it is not a fully functional social media application, it demonstrates the use of HTML for page structure and CSS for styling and layout.

## Features

- Facebook-inspired homepage design
- Clean and organized HTML structure
- Custom CSS styling
- Navigation bar and login form
- Responsive layout for different screen sizes
- Version controlled using Git and hosted on GitHub

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## Purpose

The purpose of this project was to:
- Learn the basics of Git and GitHub.
- Practice creating, committing, and pushing changes.
- Understand version control and repository management.
- Improve HTML and CSS skills by recreating a popular website layout.
